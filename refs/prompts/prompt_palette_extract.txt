用途：从风格锚图里提取 HEX 色板给 OpenCode 用
建议模型：支持视觉的 LLM
使用方式：上传 ref_verse.png / ref_chorus.png / ref_outro.png，贴下面整段

──────────────── PROMPT ────────────────
你是色彩指导。根据所附参考图，提取 8 个主色并输出 JSON，格式：
{"paper": "#......", "deep": "#......", "midtone": "#......", "accent": "#......",
 "highlight": "#......", "subtitle_band": "#......", "ink": "#......", "glow": "#......"}

要求：
- 全部 HEX；不要纯黑 #000000 或纯白 #FFFFFF（至少偏离 8%）
- 按用途命名（背景 / 中间调 / 高光 / 点缀 / 字幕带 / 墨线 / 辉光）
- 附一行说明：这张图属于 主歌 / 副歌 / 尾声 哪个色板
- 只输出 JSON + 那一行说明，不要解释
