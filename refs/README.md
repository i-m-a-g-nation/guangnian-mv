## 色板

`palette.json`：每个阶段 `paper / deep / midtone / structure / accent / highlight / subtitle_band / ink / glow` + 采样色 + 规则。
- 全局：禁纯黑/纯白；最暗 `#060A10`，最亮 `#EDE7DA`；字幕带 `y=975–1070` 保持暗而干净。

## OpenCode 落地五条

1. 形状优先：先复现大色块和剪影，再加光，最后才加纹理。
2. 细节上限：每张参考最多保留 5 个识别特征，其余合并。
3. 人物不画写实脸：只用面罩/剪影/眼睛局部。
4. 金色只做光：主歌金色面积 <2%；副歌也不做满屏贴金。
5. 一次只改一个维度（形 → 色 → 光 → 笔触），每轮出检查图对比。
