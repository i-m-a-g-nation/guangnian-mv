# 交付前质量检查（43 镜通用）

## 1. 原画保真

- 关掉相机和特效时，正确组合 `plate + layers` 应尽可能还原 `hero.png` 的构图与主体位置。
- 先对比同一帧的细墨线、衣服轮廓、水彩颗粒、舷窗圆环；不能出现背景原图残留的第二个人物。
- 原画实际只有 1672×941，当前 DEMO 等比放大到 1920×1080；今后 hero 原画推荐直接生产 >= 1920×1080，重要推镜镜头可额外提供 2304×1296 或以上素材以降低放大损失。

## 2. 时序稳定

- 重复渲染同一个整数帧，应输出相同的 PNG（同一机器、同一版本、同样资产）。
- 特效轨迹必须是 `position(frame)`，不能在导出期间读取上一帧位置并累加。
- 镜头切点不应重复或漏掉帧：半开区间 `[startFrame,endFrame)`；整片帧数 5457。

## 3. 人物动作

- 角色特写不要直接靠大幅图层平移来代替手腕、肩关节真实运动。
- S25 结束时双手仍隔一层光幕，S27 最后一帧仍不能接触；S37 才出现实体相拥。
- S37 的四姿态 `opacityKeys` 可用于粗样片；正式成片应手工检查逐处的轮廓和遮挡。交叉淡化不能自然合成任意复杂姿态。

## 4. 光影和字幕

- 画面底部 y=975–1070 是字幕叠加区；原画若有高亮地面反射（如上传的参照图），字幕合成时需要单独深色渐隐衬层，而不是永久性破坏原画。
- 金色光效只在叙事关键处加强。较远星点避免过度频繁闪烁；不可让每秒的随机纸纹造成噪点。
- 主画面输出不包含歌词；字幕单独校正句级和逐字时间后再用 FFmpeg 合成。主画面切点和歌词切点不必一致。

## 5. 存储预算与版权

- 全片未压缩图像帧会占用大量空间。1920×1080 的 PNG 序列总量常可能在数 GB 到数十 GB，视画面纹理复杂度变化。建议按章节导出、审核、编码和归档后再清理临时帧。
- 使用《光年之外》歌曲/录音和歌词做公开发布时须确认授权及平台政策。本仓库不包含音频。
